## FEN, PGN, and a move list

### Added
- Load a position by pasting a FEN. A position the editor can show is accepted, including a pawn on the first or eighth rank. A malformed FEN shows an error and leaves the board alone.
- Copy the current FEN.
- Import a PGN game from a file or from pasted text, then step through it. Export writes the current game back out as PGN.
- A move list with back, forward, start, and end. Playing a different move from the middle of the line replaces the continuation.

### Fixed
- Analysis no longer stays on the loading skeleton when the editor builds a position chess.js rejects. Tactic labels are skipped for that position; the engine lines still appear.
- Dragging the king two squares is treated as castling only when a rook is on the corner and the path between them is clear. From the starting position, Ke1-g1 no longer plants a rook on the bishop and deletes the h1 rook.
- Mate scores keep their sign, so a mate against you reads -M3 and a mate for you reads M3.
- The "already running" dialog tells you how to quit the stuck copy on the system you are using. macOS gets Activity Monitor and `killall`; Windows keeps Task Manager and `taskkill`.
