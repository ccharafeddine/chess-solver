## Fixes the Windows app not opening

### Fixed
- **The app could fail to open on Windows, and then do nothing on every later launch.** If Windows reserved the app's local port (common with Hyper-V, WSL, or Docker), v1.1.0 never showed a window and kept running in the background. It now falls back to another port, and if it truly can't start it shows an error instead of hanging.
- **The engine didn't start in the desktop app.** The multi-threaded engine needs a browser feature that the desktop shell wasn't enabling. It's now turned on explicitly, so the full-strength, multi-core engine runs as intended.
- Launching the app while it's already open now brings up the existing window, and opens a new one if there isn't one.

### Improved
- The Windows portable `.exe` now shows a splash screen while it unpacks, so you can tell it's starting.

### If v1.1.0 wouldn't open for you
A hidden v1.1.0 process may still be running. Open Task Manager, end any **Chess Solver** processes (or run `taskkill /IM "Chess Solver.exe" /F`), then launch v1.1.1.

- **macOS:** `Chess.Solver-1.1.1-universal.dmg` (Intel + Apple Silicon). It isn't notarized, so right-click the app → **Open** on first launch.
