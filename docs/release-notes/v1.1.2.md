## Windows is now a real installer, and the app starts instantly

### Fixed
- **The Windows app could show its splash screen and then never open a window.** The download carried roughly 360 MB of unused engine files, and the portable `.exe` unpacked that entire payload (about 700 MB) into a temporary folder *every single time you launched it*. On a machine with antivirus scanning each freshly written file, that left the app sitting invisible long enough to look broken. The unused files are gone, and the unpacking is gone with them.

### Windows now ships an installer
The portable `.exe` has been replaced by `Chess.Solver.Setup.1.1.2.exe`:

- Installs for the current user only, so there is **no administrator prompt**.
- Adds a desktop shortcut and a Start Menu entry, and shows up under **Settings → Apps** for a clean uninstall.
- Unpacks once at install time instead of on every launch. **The app now opens in about a second**, compared with 10-15 seconds before.
- Running a newer installer upgrades an existing install in place.

### Smaller download
The Windows download drops from **304 MB to about 165 MB**, because the six unused Stockfish builds are no longer bundled alongside the one the app actually runs. Engine strength is unchanged: it is still the full multi-threaded NNUE build using all your CPU cores.

### Upgrading from 1.1.0 or 1.1.1
Just run the installer. If an older copy is still running invisibly in the background, end any **Chess Solver** processes in Task Manager first (or run `taskkill /IM "Chess Solver.exe" /F`) — a running instance blocks new launches. If you previously created a shortcut by hand, the installer replaces it with one pointing at the new location.

### Downloads
- **Windows:** `Chess.Solver.Setup.1.1.2.exe`. SmartScreen may warn because it's unsigned: choose *More info → Run anyway*.
- **macOS:** `Chess.Solver-1.1.2-universal.dmg` (Intel + Apple Silicon). It isn't notarized, so right-click the app → **Open** on first launch.
