## Opens at the right size, and never fails to open silently

### Fixed
- **The window opened too short, so the page had a scrollbar down the side from the moment it launched.** The layout needs 850 pixels of height and the window only gave it about 710. The window now measures the page and opens sized to fit it, capped to your screen, so everything is visible without scrolling. It also has a sensible minimum size.
- **A launch could do nothing at all, with no explanation.** Only one copy of Chess Solver runs at a time, and a second launch used to exit silently. If the copy already running was stuck - or was an old version that had failed to open - every launch after that quietly did nothing, which looked exactly like the app being broken. Now a launch checks whether the running copy is actually alive: if it is, it raises that window as before; if it isn't, it tells you so and shows you how to clear it.
- **Startup can no longer hang indefinitely.** If the app's local server doesn't come up within 20 seconds, it reports the failure and exits instead of lingering invisibly and blocking future launches.

### If a launch ever reports Chess Solver is already running
End any **Chess Solver** entries in Task Manager, then start it again. From a terminal: `taskkill /IM "Chess Solver.exe" /F`.

### Downloads
- **Windows:** `Chess.Solver.Setup.1.1.3.exe`, a per-user installer (no administrator rights needed). SmartScreen may warn because it's unsigned: choose *More info → Run anyway*.
- **macOS:** `Chess.Solver-1.1.3-universal.dmg` (Intel + Apple Silicon). It isn't notarized, so right-click the app → **Open** on first launch.
