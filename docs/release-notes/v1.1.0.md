## Faster, stronger, and no more stalled analysis

### Fixed
- **Analysis no longer fails or times out when you move quickly.** A "stop" command could get lost while the engine was switching positions, which made the app rebuild the whole engine and sometimes give up with no move. Moves now get a best line within milliseconds of each position change.
- **Settings now persist between launches** (theme, number of lines, think time). Previously they reset every time the app started.
- Fonts now load in the desktop app.

### Faster and stronger engine
- Stockfish now uses **all your CPU cores** (the multi-threaded NNUE build). The previous release was accidentally running the single-threaded engine. That's roughly 4× the search speed on a 4-core machine, which means deeper, stronger analysis in the same time.
- New **Think time** setting (1s / 3s / 5s / 10s) in the ⚙ menu. The best move so far still appears instantly.
- Faster engine startup on repeat launches.

### Updates
- The app now **checks for new releases at startup** and shows a banner (plus a dot on the ⚙ gear) when one is available. You can turn this off in the ⚙ menu, and "Check for updates" is still there to run on demand.

### Other
- Opening the app a second time focuses the existing window instead of starting a second engine.

### Downloads
- **Windows:** `Chess.Solver.1.1.0.exe`, a portable build. SmartScreen may warn because it's unsigned: choose *More info → Run anyway*.
- **macOS:** `Chess.Solver-1.1.0-universal.dmg` (Intel + Apple Silicon). It isn't notarized, so right-click the app → **Open** on first launch.
